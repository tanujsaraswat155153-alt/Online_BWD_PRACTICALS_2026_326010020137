# UI/UX Assignment Practicals 11–17

These folders contain the practicals visible in the second assignment screenshot.

## Practical list
11. Apply external CSS to the earlier student profile.
12. Create a styled college admission form using CSS box model and selectors.
13. Create a responsive college webpage using the Bootstrap Grid system.
14. Create a restaurant menu using CSS, Bootstrap cards and grid.
15. Create a product/service webpage using pseudo-classes, pseudo-elements, transitions, image effects and navigation styling.
16. Create a JavaScript marks calculator for total, percentage, result and grade.
17. Create a student eligibility checker using age, attendance and marks.

## How to run
- Open each practical folder.
- Open `index.html` in a browser.
- For practicals 11, 12, 13, 14, 15, 16 and 17, keep the related `style.css` and `script.js` files in the same folder.
- Practical 13 and 14 use Bootstrap 5.3.3 from a CDN, so an internet connection is needed to load Bootstrap.
- Replace sample names, college details, email addresses, and other example information before submission.
- Practical 16 uses sample grade boundaries and a pass mark of 35 per subject.
- Practical 17 uses sample eligibility conditions: age 16+, attendance 75%+, marks 40%+. Change these if your teacher specifies different rules.
